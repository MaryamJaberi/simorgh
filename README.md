# پَرِ سیمرغ — سایت

سایتِ ایستا. هیچ بک‌اندی ندارد، هیچ بیلدی لازم ندارد، هیچ وابستگیِ npm ندارد.
فقط فایل‌های HTML و CSS و JS. هرجا بگذاریدشان بالا می‌آید.

---

## انتشار روی GitHub Pages — سه دقیقه

۱. یک ریپازیتوریِ تازه بسازید (مثلاً `par-simorgh`).

۲. **کلِ محتویاتِ همین پوشه** را داخلِ ریپو بگذارید — نه خودِ پوشه را، محتویاتش را.
   یعنی `index.html` باید در ریشهٔ ریپو باشد.

۳. پوش کنید:

```bash
git init
git add .
git commit -m "پَرِ سیمرغ"
git branch -M main
git remote add origin https://github.com/<نام-کاربری>/par-simorgh.git
git push -u origin main
```

۴. در گیت‌هاب: **Settings → Pages**
   · Source: `Deploy from a branch`
   · Branch: `main` · Folder: `/ (root)` · Save

۵. یکی دو دقیقه بعد آدرس آماده است:
   `https://<نام-کاربری>.github.io/par-simorgh/`

> فایلِ `.nojekyll` عمداً گذاشته شده تا گیت‌هاب فایل‌ها را دستکاری نکند. پاکش نکنید.

### میزبانی‌های دیگر
Netlify، Cloudflare Pages، Vercel: همین پوشه را بکشید و رها کنید. تنظیماتِ بیلد را خالی بگذارید.

## چطور محتوا را عوض کنم

| می‌خواهید… | فایلی که باید دست بزنید |
|---|---|
| متنِ خانه | `index.html` — بخشِ `<section class="blk">`ها |
| متنِ رمان | `story.html` (یا `files/story.md` را عوض و دوباره بیلد کنید) |
| اسلایدهای ارائهٔ اروپا | داخلِ خودِ `europe.html` دکمهٔ **پنل** — نیازی به ویرایشِ کد نیست |
| منوی سایت و جست‌وجو | `assets/shell.js` — آرایهٔ `NAV` بالای فایل |
| رنگ‌ها و فونت | `assets/shell.css` و `assets/page.css` — متغیرهای `--s-*` |
| تصویرها | `assets/art.js` — هر تصویر یک تابعِ SVG است |

بعد از هر تغییر در `assets/`، فهرستِ جست‌وجو دست‌نخورده می‌ماند.
اگر متنِ صفحه‌ها را عوض کردید و می‌خواهید جست‌وجو هم به‌روز شود،
پروژه را دوباره بیلد کنید (`node build-site.js`).

---

## جست‌وجو

کلیدِ `/` را در هر صفحه بزنید، یا دکمهٔ **«همهٔ مطالب»** گوشهٔ صفحه.
فهرست از `assets/search-index.json` می‌آید و کاملاً در مرورگر کار می‌کند —
هیچ سرورِ جست‌وجویی در کار نیست.

> **نکته:** اگر فایل‌ها را مستقیم از روی دیسک (`file://`) باز کنید،
> مرورگر اجازهٔ خواندنِ فایلِ فهرست را نمی‌دهد و جست‌وجو کار نمی‌کند.
> بقیهٔ سایت کار می‌کند. برای تستِ محلی: `python3 -m http.server 8080`

## چیزهایی که عمداً این‌طورند

- **هیچ ردیابی، هیچ کوکی، هیچ تحلیلگر.** تنها درخواستِ بیرونی، فونت‌های گوگل است —
  و اگر نیاید، فونتِ جایگزینِ سیستم می‌گیرد و هیچ‌چیز خراب نمی‌شود.
- **هیچ نمادِ حزبی، دولتی یا دینی** در تصویرها نیست. همهٔ نمادها از شاهنامه‌اند.
- **برآوردهای هزینه مدل‌اند، نه پیش‌بینی.** فرض‌هایشان در خودِ متن نوشته شده.
- **ابزارِ صدا-به-متن** باید دانلود شود و در کروم باز شود؛ داخلِ سایت کار نمی‌کند
  چون مدل را باید در مرورگرِ خودتان بارگذاری کند.
